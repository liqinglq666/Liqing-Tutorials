## About

**Liqing Tutorials** 是我长期维护的个人教程与科研知识库。

这里记录我在科研、材料表征、数据分析、Scientific AI、科研工具与学术工作流中的实践经验。每一篇教程尽量做到：

- **Practical** — 以真实操作流程为主，不只讲概念
- **Reproducible** — 尽量给出清晰步骤、参数入口与判断依据
- **Research-oriented** — 服务于科研数据处理与分析
- **Versioned** — 保留版本号和更新记录，便于持续迭代
- **Personal notes** — 来源于个人学习、整理与实践，不替代软件官方文档或标准规范
